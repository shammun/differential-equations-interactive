The setup

A fixed reference wave and an adjustable one, added together:

f(t) = sin t   ·   g(t) = A sin(ωt − φ)   ·   x(t) = f(t) + g(t)

Three knobs, three independent jobs: ω sets how fast g wiggles (radians per second), A sets how tall it is, φ slides it along the time axis.

The envelope, derived

Write each sinusoid as the imaginary part of a rotating complex number:

x(t) = Im( eit ) + Im( A ei(ωt − φ) ) = Im( eit [ 1 + A eiψ(t) ] )

where the exponent split works because eit · A eiψ = A ei(t + ψ), and we choose

ψ(t) = (ω − 1) t − φ    so that    t + ψ(t) = ωt − φ ✓

ψ is the phase gap: how far ahead g's arrow is of f's arrow. Now write the bracket in polar form, 1 + A eiψ = R eiα. Its modulus comes from the law of cosines on the two-vector triangle:

R(t) = √( 1 + A² + 2A cos ψ(t) )   ·   α(t) = atan2( A sin ψ, 1 + A cos ψ )

Therefore

x(t) = R(t) · sin( t + α(t) )

— a sine whose amplitude R and phase α both drift slowly. The gray curves in the applet are ±R(t).

Key consequences

Envelope range

cos ψ swings over [−1, 1], so R swings over

|1 − A| ≤ R(t) ≤ 1 + A

Full silence at the nulls needs A = 1 exactly.

Beat period

R repeats when ψ advances by 2π:

Tbeat = 2π / |ω − 1|

Closer frequencies → slower beats. ω = 1 → no beats at all.

Carrier period

The fast wiggle inside the envelope runs at the average frequency (1 + ω)/2:

Tcarrier = 4π / (1 + ω)

Clean product form (A = 1, φ = 0)

sin t + sin ωt = 2 sin( (1+ω)t/2 ) cos( (1−ω)t/2 )

Fast sine × slow cosine — the textbook beats formula, a special case of R sin(t + α).

When is it really "beats"?

The word applies when the envelope is much slower than the wiggle inside it, which needs ω close to 1. The ratio of the two time scales is

Tbeat / Tcarrier = (1 + ω) / (2|ω − 1|)

At ω = 1.1 that ratio is 10.5 — a clear, audible throb. At the applet's default ω = 1.77 it is only 1.8, which is why the default picture looks lumpy rather than like textbook beats.
