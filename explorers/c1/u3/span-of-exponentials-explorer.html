The question in plain words

We start with four functions of t:

e2t,   e−2t,   e2it,   e−2it

Their span is the collection of every function you can build as

c1 e2t + c2 e−2t + c3 e2it + c4 e−2it   (c1, …, c4 any complex numbers)

Call this collection V. Each option gives a different “kit” of functions. The question is: does that kit build exactly the same collection V — nothing more, nothing less?

The answer: options 1, 2, 4 and 5 give the same span. Option 3 does not. The tabs above walk through why, one option at a time. If the word “span” or the exponentials with i feel shaky, read the three Foundation tabs first — every option tab leans on exactly those three ideas.

The three tools we will use again and again

Tool 1 — what changes a span, what doesn’t
Multiplying a function by a nonzero number, or adding a function that is already buildable from the others, leaves the span unchanged. Merging two independent functions into one shrinks it.
Tool 2 — counting dimensions
The four starting functions are linearly independent, so V is 4-dimensional. A kit with only 3 independent functions can never rebuild it.
Tool 3 — Euler’s bridge
e2it = cos 2t + i sin 2t. With complex coefficients allowed, the pair {e2it, e−2it} and the pair {cos 2t, sin 2t} are interchangeable.

Meet the four building blocks

Two of them are real: e2t grows, e−2t decays. The other two are complex-valued, so we can’t plot them directly — but their real part is cos 2t and their imaginary part is ±sin 2t. Tick the boxes to compare.

Notice how different their shapes are: exponential growth, exponential decay, and two oscillations. No amount of the oscillating ones can imitate the growing one, and so on — that is the intuition behind “linearly independent”.

Tool 1 — What is a span, and what changes it?

Functions are hard to picture, so let’s first play the same game with arrows in the plane. Everything we learn transfers word-for-word to functions.

The span of a set of arrows is every point you can reach by scaling the arrows and adding them. Drag the coefficient sliders (orange) to build one combination (teal). The light-teal region behind it is the whole span.

What you should notice

  • Set B (rescaled): multiplying an arrow by a nonzero number (3, or −1) changes nothing about where you can reach. You just need a different slider value to get to the same point.
  • Set C (one extra arrow): adding e1+e2 adds nothing new — it was already reachable. The span is still the whole plane; there are now simply many slider settings that give the same point.
  • Set D (merged into one): replacing two independent arrows by their single sum throws away a direction. You can only reach a line. This is exactly what option 3 does.
  • Set E (two combos): two combinations of the originals can still span the plane, as long as they don’t point along the same line. This is what option 5 does with cos(2t − π/3) and sin 2t.
The two rules that keep a span the same:
(1) Multiply any function by a nonzero number.
(2) Add to the list — or remove from the list — a function that is a combination of the others.
More generally: a new set spans the same space as the old one exactly when every old function is buildable from the new ones and every new function is buildable from the old ones.

The “count the dimensions” shortcut

If a space needs 4 independent directions (it is 4-dimensional), any kit with only 3 functions builds at most 3 directions, so it can never fill the space. Conversely, if a kit of functions all live inside the space and contains 4 independent ones, it fills the space completely. This is the quickest way to judge options 3 and 4.

Tool 2 — Why eαt and e−αt are linearly independent

This is the “quick recap” at the top of the official solution. It looks dense, so let’s do it slowly.

What “linearly independent” means here: the only way to get the zero function (zero at every t) as a eαt + b e−αt is the boring way, a = b = 0. If some other choice also gave zero, the two functions would be “dependent”.

The proof, step by step (with α ≠ 0)

  1. Suppose some numbers a, b make it zero for all t:
    a eαt + b e−αt = 0   for every t
  2. Plug in t = 0. Since e0 = 1: a·1 + b·1 = 0, so a + b = 0, i.e. b = −a.
  3. Differentiate both sides. An equation that holds for all t stays true after differentiating (the derivative of the constant 0 is 0):
    αa eαt − αb e−αt = 0
    (chain rule: the derivative of eαt is α eαt, and of e−αt is −α e−αt).
  4. Divide by α — allowed because α ≠ 0: a eαt − b e−αt = 0.
  5. Plug in t = 0 again: a − b = 0, i.e. a = b.
  6. Combine: b = −a and b = a force a = −a, so 2a = 0, so a = 0, and then b = 0. The only solution is the boring one. ✔
Why step 3 is the clever move. Value at 0 tells us about a + b. Slope at 0 tells us about a − b. Two independent facts pin down two unknowns. Nothing about the proof used that α is real — so it works for α = 2i too, which is why e2it and e−2it are independent.

Move the sliders. The teal readouts are the two facts the proof uses: the value at 0 and the slope at 0. The curve is flat zero only when both are zero — and that happens only at a = b = 0.

From two functions to all four

The same “evaluate, differentiate, evaluate…” idea extends: for exponentials eα1t, …, eαnt with distinct exponents αk, the functions are always linearly independent. Our exponents 2, −2, 2i, −2i are four different numbers, so e2t, e−2t, e2it, e−2it are independent and V is 4-dimensional. (You can also just look at the shapes in the Overview tab: growth, decay and oscillation can’t imitate one another.)

Tool 3 — Euler’s bridge between e±2it and cos 2t, sin 2t

Euler’s identity says

eiθ = cos θ + i sin θ

With θ = 2t and θ = −2t (remember cos is even, sin is odd):

e2it = cos 2t + i sin 2t,    e−2it = cos 2t − i sin 2t

So e2it and e−2it are built from cos 2t and sin 2t. Now go the other way — add the two equations, and subtract them:

cos 2t = e2it + e−2it2,     sin 2t = e2it − e−2it2i = −i2 e2it + i2 e−2it
Here is why the problem says “with complex coefficients”. To build sin 2t from e±2it we needed the coefficient 1/(2i) = −i/2, and to build e2it from cos and sin we needed the coefficient i. With real coefficients only, neither direction would be possible. With complex coefficients, the pairs are perfectly interchangeable:
Span{ e2it, e−2it } = Span{ cos 2t, sin 2t }
And since e2it, e−2it are independent (Tool 2), so are cos 2t, sin 2t — a 2-dimensional space either way.

Option 1 Same span ✔

Span{ e2t, e−2t, cos 2t, sin 2t }

What changed compared with the original? The two real exponentials are untouched. The pair e2it, e−2it was swapped for the pair cos 2t, sin 2t. Tool 3 says these pairs are interchangeable. That is the whole argument — but let’s check it the careful way, in both directions.

  1. Every function in option 1 lives in V. e2t and e−2t obviously do. And
    cos 2t = ½ e2it + ½ e−2it,   sin 2t = −(i/2) e2it + (i/2) e−2it
    are combinations of the originals with (complex) coefficients. So Span(option 1) ⊆ V.
  2. Every original function lives in Span(option 1).
    e2it = cos 2t + i sin 2t,   e−2it = cos 2t − i sin 2t
    So V ⊆ Span(option 1).
  3. Both inclusions hold, so the spans are equal. ✔
Shortcut with Tool 2: option 1 has four independent functions (distinct shapes: growth, decay, cos, sin), all inside the 4-dimensional V. Four independent directions inside a 4-dimensional space must fill it.

Option 2 Same span ✔

Span{ e2t, −e−2t, 3 cos 2t, −sin 2t }

What changed compared with option 1? Only scaling: e−2t became −e−2t, cos 2t became 3 cos 2t, sin 2t became −sin 2t. Rule (1) from Tool 1: multiplying by a nonzero number never changes a span. Why? Because the scaling can always be undone by the coefficient.

  1. Anything built from option 1, say a e2t + b e−2t + c cos 2t + d sin 2t, can be rewritten with option 2’s functions:
    = a·(e2t) + (−b)·(−e−2t) + (c/3)·(3 cos 2t) + (−d)·(−sin 2t)
    Every step just divides by the scale factor (−1, 3, −1), all nonzero.
  2. And the reverse is even easier: −e−2t, 3 cos 2t, −sin 2t are obviously combinations of option 1’s functions.
  3. So Span(option 2) = Span(option 1) = V. ✔
2-D picture: in the Tool 1 tab, set B { 3e₁ , −e₂ } reaches every point that { e₁ , e₂ } reaches — the sliders just need different numbers. Same thing here.

Play: same targets, option 2’s kit

Watch the teal coefficients: they are the orange ones divided by −1, 3 and −1. The rebuilt curve still lands exactly on the target.

Option 3 Different span ✘

Span{ e2t + e−2t, cos(2t)/2, sin 2t }

What changed? Two things. The cos 2t got scaled by ½ — harmless (Tool 1, rule 1). But the two independent functions e2t and e−2t were merged into the single function e2t + e−2t. That throws away a direction.

Argument A — count the functions

The kit has only 3 functions, so its span is at most 3-dimensional. V is 4-dimensional (Tool 2). A 3-dimensional space cannot equal a 4-dimensional one. Done — this alone settles it. ✘

Argument B — show a specific function of V that option 3 cannot build

Let’s try to build the very first original function, e2t. Suppose we could:

e2t = A (e2t + e−2t) + B cos(2t)/2 + C sin 2t
  1. Move everything to one side and group by the four independent building blocks:
    (1 − A) e2t + (−A) e−2t + (−B/2) cos 2t + (−C) sin 2t = 0
  2. Because e2t, e−2t, cos 2t, sin 2t are linearly independent, every coefficient must be 0 (that’s what independence means):
    1 − A = 0,   −A = 0,   B = 0,   C = 0
  3. The first two say A = 1 and A = 0 at the same time. Impossible. So e2t is not in Span(option 3). ✘
The general rule for this kit: anything built from option 3 looks like A e2t + A e−2t + (B/2) cos 2t + C sin 2t. The coefficients of e2t and e−2t are forced to be equal. So option 3 only reaches the functions of V whose growing and decaying parts have the same weight. It misses e2t, misses e−2t, misses 3e2t − e−2t, and so on.

The official solution’s sentence, decoded

“Combining e2t and e−2t into e2t + e−2t is similar to replacing e1 = (1,0) and e2 = (0,1) with v = (1,1).” In the plane, e1 and e2 reach every point; the single arrow (1,1) only reaches the diagonal line. Go to the Tool 1 tab and pick set D { e₁+e₂ } to see exactly this collapse. The functions e2t and e−2t play the roles of e1 and e2.

Play: try to build a target with option 3’s kit — and watch it fail

The kit can match the target only when c1 = c2. Otherwise the best it can do is use the average (c1+c2)/2, and the dashed teal curve visibly misses the orange target. Press “e2t” to see the classic failure, then “equal weights” to see the one case that works.

Option 4 Same span ✔

Span{ e2t, e−2t, e2t − e−2t, cos 2t, sin 2t }

What changed compared with option 1? One extra function was added: e2t − e−2t. Note the difference from option 3: here e2t and e−2t are still both present. Nothing was removed.

  1. The extra function is redundant. e2t − e−2t = 1·e2t + (−1)·e−2t — already buildable from two other members of the kit. Rule (2) of Tool 1: adding a function that is a combination of the others does not change the span.
  2. So Span(option 4) = Span{ e2t, e−2t, cos 2t, sin 2t } = Span(option 1) = V. ✔
Five functions, four dimensions. The kit is “too big”: there is one redundant function, so each target can be built in infinitely many ways. That is not a problem for the span — the span only asks which functions are reachable, not how many ways.
2-D picture: Tool 1, set C { e₁ , e₂ , e₁+e₂ } — still the whole plane, just with a redundant third slider.

Option 5 Same span ✔

Span{ e2t, e−2t, e2t − e−2t, cos(2t − π/3), sin 2t }

What changed compared with option 4? Only one thing: cos 2t was replaced by the phase-shifted cos(2t − π/3). So the question becomes: does { cos(2t − π/3), sin 2t } span the same 2-dimensional space as { cos 2t, sin 2t }? The official solution says “apply some trigonometric identities”. Here they are.

  1. Expand the phase shift with cos(x − y) = cos x cos y + sin x sin y, using cos(π/3) = ½ and sin(π/3) = √3/2:
    cos(2t − π/3) = ½ cos 2t + (√3/2) sin 2t
    So the new function is a combination of cos 2t and sin 2t → it lives in V. (One direction done.)
  2. Solve back for cos 2t. Multiply by 2 and rearrange:
    cos 2t = 2 cos(2t − π/3) − √3 sin 2t
    So cos 2t is buildable from option 5’s kit. Since sin 2t is in the kit directly, and e±2t are too, every function of option 1 (hence of V) is buildable. (Other direction done.)
  3. Both directions hold, so Span(option 5) = V. The extra e2t − e−2t is redundant exactly as in option 4. ✔
Check with numbers at t = 0: left side cos 0 = 1. Right side: 2 cos(−π/3) − √3 sin 0 = 2·½ − 0 = 1. ✔ At t = π/4: left cos(π/2) = 0; right 2 cos(π/6) − √3 sin(π/2) = 2·(√3/2) − √3 = 0. ✔

Why the shift π/3 is fine, and which shift would not be

For a general shift φ: cos(2t − φ) = cos φ · cos 2t + sin φ · sin 2t. To recover cos 2t we divide by cos φ: cos 2t = (cos(2t − φ) − sin φ · sin 2t) / cos φ. This works whenever cos φ ≠ 0. It would fail at φ = π/2, because cos(2t − π/2) = sin 2t — the “new” function would just be a copy of sin 2t, and we would be back in an option-3 style collapse. For φ = π/3, cos φ = ½ ≠ 0, so all is well.

The official solution, sentence by sentence

  • “For any non-zero α, exp(αt) and exp(−αt) are linearly independent…” — the evaluate / differentiate / evaluate proof (Tool 2). It is stated for general α so that it covers both α = 2 and α = 2i.
  • “Invoking Euler’s identity … cos(αt) and sin(αt) are linearly independent” — because they are invertible combinations of the independent pair e±iαt (Tool 3).
  • “The first, second and fourth options span the same set” — swap the pair (option 1), rescale (option 2), add a redundant function (option 4).
  • “The third option does not … like replacing e₁, e₂ with v = (1,1)” — merging two independent things into one loses a direction (Tool 1, set D).
  • “The fifth option does … trigonometric identities on cos(2t − π/3)” — the angle-difference formula shows cos(2t − π/3) and sin 2t are just a “rotated” pair spanning the same plane as cos 2t and sin 2t.
