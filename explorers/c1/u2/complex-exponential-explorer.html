What does e(a+bi)t actually draw?

Two real knobs, a and b, decide everything. One sets how far the point is from the origin; the other sets which way it turns. Start with the algebra, then turn the knobs.

Nothing here is a trick. Each line uses one rule, named underneath it.

Reading the answer as polar form

Polar form says any nonzero complex number is r eiθ — a distance r and an angle θ. Line the final expression up against that template and the two ingredients fall out:

e(a+bi)t  =  eat  ·  ei bt   ↔   r eiθ

a controls the radius

r(t) = eat

Notice b is nowhere in this expression. The distance from the origin depends on a alone.

b controls the angle

θ(t) = bt

And a is nowhere in this one. The direction depends on b alone.

Why that separation is the whole story

Because the two knobs never touch each other, you can reason about them one at a time and then just combine the verdicts. That is what the next tab lets you do by hand.

Turns completed = |bt| ÷ 2π — how many full laps around the origin the point has swept since t = 0. One full circle is 2π radians, so dividing the accumulated angle by 2π converts radians into revolutions. A reading of 1.50 means one and a half times around. When b = 0 it never leaves 0.00, because the point never turns.

The radius graph is an exponential; the angle graph is a straight line through the origin with slope b. A straight line for the angle is exactly what “turning at a constant rate” means.

Only four shapes are possible

Each knob has three states (positive, zero, negative), but the shape depends only on whether each is zero. Click a tile to load it into the explorer.

Why a spiral is called a spiral

When both knobs are on you can eliminate t altogether. From θ = bt we get t = θ/b, and substituting into r = eat:

r = e(a/b)θ

The radius grows exponentially in the angle — the definition of a logarithmic spiral. The ratio a/b is the only thing that sets how tightly it winds: a small |a/b| means many turns per doubling, a large one means it escapes after barely turning at all.

Same shape you get from the powers of a fixed complex number, where r = |w|n and θ = n arg(w). There the parameter jumps in whole steps; here it flows continuously.

Example 1 — when is the trajectory a line?

A line means the direction never changes. The direction is θ(t) = bt, and the only way that stays constant for all t is b = 0. Then

e(a+0i)t = eat(cos 0 + i sin 0) = eat · 1 = eat

which is a positive real number sliding along the positive real axis. If a = 0 as well it is frozen at 1 and traces nothing, so we also need a ≠ 0.

Answer: b = 0, a any nonzero value.

Strictly it is a ray, not a full line: eat is always positive, so the point never crosses the origin onto the negative side.

Example 2 — describe e(−5−2i)t as t → ∞

Match it to the template e(a+bi)t: here a = −5 and b = −2. Split it:

e(−5−2i)t = e−5t ei(−2t)

Now read the two knobs separately:

Radius: e−5t → 0 as t → ∞, so the point moves inward.
Angle: θ = −2t is decreasing, so the point turns clockwise.

Both knobs are nonzero, so the shape is a spiral, and the two verdicts combine:

Answer: it spirals clockwise as it moves inward.

The slider only reaches a = −1; a = −5 collapses to the origin too fast to see. The shape is the same, just wound far more tightly.
