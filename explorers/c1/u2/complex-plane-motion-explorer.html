How r and θ are calculated (live)

For any point x + iy:   r = √(x² + y²)  and  θ = arctan(y / x) — the angle of the line from the origin to the point.

    The quick test for any of these questions

    Write f(t) = x(t) + i·y(t), then ask:

    Is θ constant? (is y/x constant, or is y = 0?) Yes → radial: it stays on one spoke from the origin. Then r growing = outward, r shrinking = inward.
    Is one coordinate a non-zero constant? Yes → a horizontal or vertical line that misses the origin. (If the constant is 0 the line passes through the origin and the motion is radial.)
    Is r constant while θ turns? Yes → circle. r and θ both changing with rotation → spiral. Both coordinates changing with no rotation → some curve (parabola, hyperbola…).

    The recurring trap: graphing y = t² on (t, t²) axes gives a parabola, and y = 1/t gives a hyperbola. But in the complex plane the point is (Re f(t), Im f(t)) — t is not an axis, only a knob. Plot what the number is, not what it looks like as a graph.
